# Destiny Travels API

## Project Description
Destiny Travels API is a backend application developed using Node.js, Express.js, MongoDB and Mongoose.

It manages travel destinations using CRUD operations and advanced database queries.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- Postman

## Database
Database Name: destiny_travels

Collection Name: destinations

## Features
1. Add destinations.
2. Retrieve all destinations.
3. Retrieve destination by ID and name.
4. Update destinations.
5. Filter destinations by category and price.
6. Sort destinations by price and rating.
7. Implement pagination.
8. Retrieve unique categories.
9. Count destinations.
10. Delete destinations.

## Run the Project

Install dependencies:

npm install

Start the server:

npm run dev

Server URL: http://localhost:5000
